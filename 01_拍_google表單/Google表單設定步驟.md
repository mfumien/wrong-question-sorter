S# 01_拍：Google表單設定步驟 (2A方案)

## 1. 建表單 (3分鐘)

1. 到 forms.google.com → 空白表單，改名 `錯題拍照上傳_班級`
2. 新增題目 (完全照 `表單欄位定義.csv`)：
   - 學號 (簡答，必填，驗證：數字)
   - 姓名 (簡答，必填)
   - 科目 (下拉：國文/英文/數學/物理/化學/生物/地科/歷史/地理/公民)
   - 單元猜測 (簡答，非必填，學生先自己寫，給AI對答案用)
   - 錯題照片 (檔案上傳，必填，只允許圖片，最多3張，單檔10MB)
   - 原始作答/錯因自述 (段落，必填：我原本寫什麼？哪裡不懂？)
3. 設定 → 回應 → 連結到試算表 → 建立 `錯題庫_原始表`
4. 表單說明貼上拍攝規範：
> 只拍一題、橫放填滿畫面、開燈避陰影、手寫訂正用紅筆、截圖要含完整題幹+選項

## 2. 建Drive收件匣

1. Drive建資料夾 `錯題收件匣`，表單上傳的檔案會自動進此資料夾的子資料夾
2. 共用設定：老師可檢視，全班可上傳(經由表單即可，不需直接共用)

## 3. 貼上Apps Script自動整理 (已附 .gs檔)

1. 開 `錯題庫_原始表` → 擴充功能 → Apps Script
2. 把 `AppsScript_自動命名與整理.gs` 全貼上 → 儲存 → 執行 `setupTrigger` 授權一次
3. 功能：自動把檔名改成 `學號_科目_日期_序號.jpg`、補上 `狀態=待辨識`、擋下非圖片/超過3張的重複送出

## 4. 驗收

* 手機拍1張 + 電腦截圖1張上傳，Sheets應多2列，Drive有多2檔，狀態欄為待辨識
* 把該列的圖片連結下載到 `02_辨_python圖轉文/input_images/` 跑下一步
