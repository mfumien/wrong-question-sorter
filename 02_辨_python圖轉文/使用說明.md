# 02_辨：Python圖轉文 使用說明

## 安裝 (教室電腦一次即可)

```bash
cd 02_辨_python圖轉文
pip install -r requirements.txt
```

## 使用 (學生每次)

1. 把Google表單下載的照片 / 手機截圖丟進 `input_images/`
   檔名建議 `學號_科目_日期.jpg`，例 `312001_數學_20251001.jpg`
2. 跑：
```bash
python3 ocr_vision.py
```
3. 看 `output_ocr.json`：
   - `question_text_raw`：全部辨識文字
   - `stem_guess` / `options_guess`：初步切出的題幹/選項
   - `confidence` <0.55 或 `need_retake=true` → 照「重拍規範」重拍
4. 把 `output_ocr.json` 丟給 opencode (muse-spark-1.3) 做03拆解

## 預處理做了什麼

自動放大短邊到1200px、自動對比、銳化，歪斜嚴重的請先用手機內建裁切拉正。

## 換引擎 (進階)

預設 RapidOCR 本機免費。若要更高準確率的手寫數學式，可再加 Gemini Vision 當第二通道，本專題先用本機版即可達標。
