# 未分類區說明

此區放 `organize.py` 判斷為未分類的圖片，條件任一成立即進來：

- `need_retake=true` 或 `confidence < 0.55` 或字數 `<10`
- 例：模糊、手震、只拍到半題、長條截圖字太小(RapidOCR=0)

處理方式：
1. 看 `分類結果總表.csv` 的 `原因/路徑` 欄重拍
2. 重拍後丟回 `02_辨_python圖轉文/input_images/` 再跑一次
3. 若本機OCR一直0字(如英文細明體長條圖)，直接把圖拖進opencode用muse-spark看圖補救，參考 `110317` 那題的做法

本批5張全數已分類，此資料夾目前為空是正常的。
